# Birth Rule

> A slow stare at Wolfram code
>
> Live page: [wherewindstay.github.io/birth-rule](https://wherewindstay.github.io/birth-rule/)

Birth Rule is a one-dimensional cellular automaton drawn in the browser. A birthday, today's date or a random date sets the first row, the order of the rules and the color. One row is added per second. The same date and time give the same picture.

## Usage

- Choose a month and day, and a year if wanted, then press "Start with this birthday".
- "Today" uses today's date. "Random date" picks a day at random. "Clear" removes the birthday.
- "Pause" stops the rows. "Save PNG" saves the current picture.
- "Algorithm" and "Details" show how the picture is computed.
