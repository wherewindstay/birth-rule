# Birth Rule

> Wolfram code 를 천천히 바라보기
>
> 화면: [wherewindstay.github.io/birth-rule](https://wherewindstay.github.io/birth-rule/)

브라우저에서 그려지는 1차원 셀룰러 오토마타. 생일·오늘 날짜·무작위 날짜가 첫 줄, 규칙 순서, 색을 정함. 1초에 한 줄씩 쌓임. 같은 날짜와 시각이면 같은 그림이 나옴.

## 사용법

- 월·일(필요하면 연도)을 고르고 「Start with this birthday」를 누름.
- 「Today」는 오늘 날짜, 「Random date」는 무작위 날짜, 「Clear」는 생일 삭제.
- 「Pause」는 줄 쌓기 정지, 「Save PNG」는 현재 그림 저장.
- 「Algorithm」·「Details」에 계산 방식이 있음.
